TELEGRAM SETUP TUTORIAL

JEV hanya menyimpan token secara terenkripsi di server.

  1. Buka Telegram, cari akun resmi @BotFather, lalu tekan Start.
  2. Kirim perintah /newbot. Ikuti instruksi dan simpan Bot Token yang diberikan.
  3. Buka chat bot baru tersebut, lalu kirim pesan pertama, misalnya /start.
  4. Buka https://api.telegram.org/botTOKEN/getUpdates. Ganti TOKEN dengan token bot. Cari nilai message.chat.id.
  5. Kembali ke JEV → Settings → Telegram Connection. Isi Bot Token dan Chat ID.
  6. Centang ENABLE, lalu tekan SAVE & TEST.
  7. Status CONNECTED berarti JEV berhasil memvalidasi bot dan mengirim pesan uji.
  8. Jika gagal, pastikan token benar, Chat ID tidak memakai spasi, dan bot sudah menerima pesan pertama.
